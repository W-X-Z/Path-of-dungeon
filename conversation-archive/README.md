# Path of Dungeon — 기획부터 MVP까지

정리 기준일: 2026-09-21

**무작위로 주어지는 방을 노선으로 연결하고, 함정의 순서와 쿨타임으로 인간 침입대를 막는 던전 빌드 게임.**

이 폴더는 현재 대화의 초기 아이디어, 시각 방향, 메커니즘 논의, 레퍼런스 조사, MVP 제작 결과를 정리한 아카이브입니다. 전체 대화의 원문 덤프가 아니라 주제별 정리이며, 사용자 발언은 별도 문서에 원문 발췌로 보존했습니다.

## 유지할 중심 방향

- **Mini Metro를 참고한 선 연결과 지도 가독성.**
- **마왕군 순찰을 제외한 던전 빌드.**
- 방과 함정의 쿨타임, 침입자 파티의 상성 조합, 방과 방의 연계를 실력 요소로 구성.
- 게임 규칙·화면·입력·오디오를 분리한 모듈형 코드.
- 새 콘텐츠의 제작 비용뿐 아니라 조합 검증과 밸런스 유지 비용까지 고려.

## 기록의 상태

| 구분 | 상태 |
| --- | --- |
| 사용자 요구 | 현재 대화에서 명시한 방향을 정리 |
| 설계 제안 | 어시스턴트가 제안한 안으로, 개별 항목을 최종 확정으로 취급하지 않음 |
| MVP | 로컬 코드와 기존 검증 기록을 확인해 구현 상태 정리 |
| 플레이 평가 | 사용자 플레이 피드백은 아직 기록되지 않음 |
| GitHub 게임 코드 | 직전 작업에서 업로드가 보류됨. 이 아카이브 작성 시작 시 원격 저장소는 비어 있었음 |
| 이번 반영 범위 | `conversation-archive/` 아래의 문서와 이미지 |

## 선호한 시각 방향

![사용자가 선호한 컨셉 이미지](assets/preferred-concept.png)

이미지의 색상과 노선도 표현을 참고했습니다. 오크 주둔지 등 초기 그림 속 표현을 모두 게임 규칙으로 확정한 것은 아니며, 이후 사용자가 방·함정 중심의 방향을 명시했습니다.

레퍼런스 문서는 대화 당시의 조사를 보존한 것으로, 이번 아카이브 작업에서 새로 최신성을 조사한 자료는 아닙니다. 게임 비용 평가는 원작의 실제 제작비가 아니라 해당 요소를 이 프로젝트에 도입할 때의 상대적인 설계 판단입니다.
